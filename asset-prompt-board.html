BUILDING 13 // ART DEPARTMENT

Image Prompt Board

Edit any prompt, then use its button to copy the whole thing directly into an image generator. These are the eight image assets the current game actually loads. They are written to preserve the game’s atmospheric elevator identity while leaving the interface text and motion to the app.

Export to the exact filename shown on each card. Do not generate text, numbers, logos, watermarks, interface buttons, or baked-in UI—the game lays those on top. Audio, word data, and the unused supplied images are listed in the customization catalog, but they are not image-generation targets.
PAIR ART WITH THE NO-CODE THEME PRESET

Use assets/data/theme.json to coordinate color roles, lobby copy, elevator-button styling, and cinematic timing with replacement art. Start from the shipped Default Copper preset; invalid or missing values quietly retain safe built-in defaults. Exact fields and limits are in the theme catalog.
